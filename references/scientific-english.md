# Scientific English

Use this reference when intended meaning is explicit enough to preserve during English drafting or revision.

## Editing Order

### 1. Paragraph function and information flow

Give each paragraph one dominant job, place familiar context before new information when useful, connect the subject to the paragraph topic, and make non-obvious logical relations explicit.

### 2. Sentence agency and emphasis

Name the actor when agency matters, prefer strong finite verbs over stacked abstract nouns, place the main result where readers can find it, and use passive voice only when the process or object deserves focus.

### 3. Concision, parallelism, and ambiguity

Remove words without meaning, keep comparable items parallel, replace unclear references, avoid opaque noun strings, and preserve evidence-required hedges.

### 4. Grammar and conventions

Check agreement, tense, articles, prepositions, punctuation, modifier attachment, terminology, abbreviations, units, capitalization, and hyphenation. Follow the target journal when it conflicts with a generic preference.

## Meaning-Preservation Gate

Never introduce or strengthen statistical significance, causality, mechanism, novelty, priority, universality, permanence, completeness, or certainty. Do not delete limitations or uncertainty merely to shorten prose.

## Output Contract for Substantial Edits

Return scientific issues, a safe revision, meaning-sensitive changes with reasons, and surface edits. If the user requests “more impact,” increase precision and emphasis through structure and quantitative evidence, not exaggeration.

## Quick Audit

Check antecedents, modifier attachment, main verbs, complete comparisons, section-appropriate tense, and whether every claim stays within supplied evidence.
